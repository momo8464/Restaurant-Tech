# 🍽️ Restaurant Tech

Bienvenue sur le projet **Restaurant Tech**, un site web vitrine dédié à un restaurant proposant une cuisine africaine moderne et savoureuse.

Le site permet aux visiteurs de découvrir le restaurant, consulter son menu et contacter l'établissement pour obtenir des informations ou passer une commande.

---

## 📌 Présentation du projet

**Restaurant Tech** est un projet web réalisé en **HTML5 et CSS3**.

L'objectif est de créer un site simple, moderne, responsive et facile à utiliser, tout en mettant en valeur la cuisine africaine.

Le site est composé de plusieurs pages :

- 🏠 **Accueil** : présentation du restaurant et de son histoire.
- 🍛 **Menu** : présentation des plats disponibles et de leurs prix.
- 📞 **Contact** : formulaire permettant aux visiteurs de contacter le restaurant.
